# Bravu Web Browser 🌐

A fast, lightweight, and reliable web browser built for Android devices.

---

## 🚀 Features
* **Fast Browsing:** Optimized engine for quick page loads.
* **Simple UI:** Clean and easy-to-use user interface.
* **Lightweight:** Designed to run smoothly without taking up much memory.

---

## 📥 Download & Install
You can download the latest Android application package (`.apk`) directly from our releases page:

👉 **[Download Bravu APK](https://github.com/aroshfaizurrahman/Bravu-Web-browser/releases/latest)**

### How to Install:
1. Download the `.apk` file above on your Android device.
2. Tap the downloaded file to install.
3. If prompted, enable **"Install from unknown sources"** in your browser/device settings.
